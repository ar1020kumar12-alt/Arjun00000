# Student Hub - Netlify Ready

Upload this folder/repository to Netlify as a static site.

- Main page: `index.html`
- Publish directory: `.`
- No build command is required.

## Multiplayer backend
The multiplayer/friends/chat features use a Render backend. In `index.html`, replace:
`https://YOUR-STUDENT-HUB-BACKEND.onrender.com`
with your real Render backend URL after deployment.
